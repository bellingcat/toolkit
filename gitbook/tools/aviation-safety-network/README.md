# Aviation Safety Network

## URL

https://aviation-safety.net/

## Description

\[\[ A full description of the tool, any background information needed to use it. What problem does it solve? Can you give an example use case? ]]

The core of Aviation Safety Network is its vast databases if aviation occurrences. The main accident database contains descriptions of over 23,000 accidents involving airliners, military transport aircraft, and corporate jets, dating back to 1919. The information in this core database is primarily derived from official government agencies, such as air accident investigation boards and civil aviation authorities.

Additionally, ASN hosts the "ASN Wikibase", a community-updated database of over 258,000 accidents involving other types of aircraft like light aircraft, helicopters, gliders, and UAVs. The site also maintains a drone database with over 15,000 reports of sightings and incidents.

ASN may be used to assist in building identities, timelines, contexts, and trends as following:

* Establishing Historical Fact: Provides a definitive, reliable record of aviation incidents, crucial for verification of events.
* Cross-Referencing Identities: For incidents like the MH17 shoot-down, OSINT investigators including Bellingcat used data from sources like ASN to verify the location, timing, and details of a crash, which was critical to confirming the event's authenticity and attributing responsibility.
* Contextualizing Incidents: Offers detailed descriptions, phases of flight, and accident locations to understand the full circumstances of an occurence.
* Trend analysis: Provides statistical data and dashboards that allow for the analysis of accident rates and safety trends over time.

## Requirements

* Internet connection and modern web browser to access the public website.
* Membership with the Flight Safety Foundation or paid access for full database downloads or API access.

## Limitations

* Free Access vs. Full Data: The public website and its basic dashboards are free, but for in-depth data analysis or bulk data, you need a paid subscription or a membership with the Flight Safety Foundation.
* Community-Sourced Data: Information in the "ASN Wikibase" is user-submitted and vetted by ASN staff, but it may not carry the same immediate authority as the core database sourced from official government reports.
* Scope: While vast, the database is primarily focused on accidents and incidents; it does not contain the same depth of information on every flight as a service like Flightradar24.
