# Epieos

## URL

[https://epieos.com/](https://epieos.com/)

## Description

Epieos is a search engine that automatically searches an array of different websites for a single email address or phone number at the same time. Basic searches will return results found on Google, Gravatar, Trello, Duolingo, Strava, Vivino, Flicker, Have I Been Pwned?, and Phonechecker.

Basic searches are free, but email searches that include emailchecker and Plex are limited to members only, which includes both paid and free accounts. The "Osinter" paid account level, which costs €30/month, includes, in addition to the free modules, searches that include Skype, LinkedIn, Nike Run Club, FitBit, Github, Asics Runkeeper, Facebook, Proton Mail, Etsy, DropBox, Foursquare, Chess.com, Substack, and Notion.

## Requirements

A basic search can be performed in a web browser with no other prerequisites.&#x20;

## Limitations

Epieos only searches for accounts and information through the listed websites. It is not an exhaustive search of everywhere that an email or phone number may appear. Use it as a starting place for research, not an endpoint.

## Ethical Considerations

As with all search engines, Epieos only returns results that it finds, it doesn't independently verify them. Just as if you found this result through any other search engine, you should attempt to investigate the connection yourself.

Epieos is based in Europe and is thus subject to European privacy laws. The site also claims not to log any of the searches you perform with it. Despite these assurances, it is always best to be cautious when working with others' personal information such as email addresses and phone numbers. Take care to avoid accidentally publishing personal information in the course of your investigation.

## Guide

To use Epieos, simply go to the website, click either email or phone number for the type of search you wish to perform, and enter the email or phone number in the search box. The website will likely ask for a Captcha and then return whatever information it finds.

## Tool provider

Epieos is owned and operated by EPIEOS SAS, a company headquartered in Paris and founded by open-source investigator [Sylvain Hajri](https://www.linkedin.com/in/shajri/).
